# 绿色军团 — 热座回合制策略游戏

> Green Army Men — Hotseat Turn-Based Strategy Game

基于 Pygame 的本地热座（Hotseat）回合制策略游戏，支持 2~4 人轮流在同一台电脑上操作。灵感来自《玩具兵大战》《文明》《红色警戒》等经典策略游戏。

---

## 快速开始

### 环境要求
- Python 3.8+
- Pygame 2.x

```bash
pip install pygame
```

### 启动方式

**Windows：** 双击 `start.bat`

**命令行：**
```bash
cd projects/strategy-game
python main.py
```

## 游戏规则

### 目标
摧毁所有敌方大本营，或消灭所有敌方单位。

### 流程
1. 每位玩家在自己的回合操作所有己方单位
2. 单位每回合可：**先移动 → 后攻击**（或跳过/驻扎）
3. 操作完成后白色光圈消失，该单位本回合不可再动
4. 点击「结束回合」轮到下一位玩家

### 单位行动状态
- **白色光圈**：该单位本回合尚未行动
- **无光圈**：已行动完毕，等待下一回合

### 战斗公式
```
真实伤害 = max(0, 攻击方伤害 − 防守方护甲)
```
- 每个单位每回合攻击一次（装甲车攻击 3 次）
- 轰炸机每 2 回合攻击一次（装弹 1 回合）

### 金钱与经济
- 起始资金：**10 金币**
- 大本营每回合产出金币（T1: +3, T2: +5, T3: +8）
- 据点被占领后每回合产出金币（+3）
- 资源采集器每回合产出金币（+3）

### 大本营升级
| 等级 | 费用 | 时间 | 效果 |
|:---:|:----:|:----:|:-----|
| T1→T2 | 🪙10 | ⏳3 回合 | HP 50, 护甲 0.5, +5金币, 双联炮台 |
| T2→T3 | 🪙30 | ⏳8 回合 | HP 120, 护甲 1, +8金币, 终极炮台 |

### 建筑自回血
所有建筑连续 2 回合未受攻击后，从第 3 回合起每回合自动恢复 **2 HP**，受击即中断。

### 据点系统
- 地图上分布中立据点，初始 20 HP、0 护甲
- 谁先打爆最后一滴血 → 据点归谁
- 占领瞬间回复 30% HP（取整）
- 占领后自动获得 T2 级防御炮台（2×2 伤害，射程 5）
- 占领后每回合 +3 金币

## 地图

- **尺寸**：80 × 80 网格
- **地形**：草地、森林（移速×2）、山地（移速×3）、水域（不可通行）、道路（移速×0.5）

## 开发信息

- **引擎**：Python 3 + Pygame
- **架构**：单文件 `main.py`，面向对象设计
- **类结构**：`Game` → `GameEngine` / `Renderer` / `Camera` / `SelectionManager`
  - `Unit` / `Building` 继承自 `Entity`
  - `Pathfinder` 提供 BFS 移动范围 + A* 寻路
  - `Button` 提供 UI 按钮系统
- **设计文档**：`encyclopedia/index.html`（兵种/装备/建筑数据源）
