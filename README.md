# 绿色军团 — 热座回合制策略游戏

> Green Army Men — Hotseat Turn-Based Strategy Game

基于 HTML5 Canvas 的本地热座（Hotseat）回合制策略游戏，支持 2~4 人轮流在同一台电脑上操作。灵感来自《玩具兵大战》《文明》《红色警戒》等经典策略游戏。

---

## 快速开始

直接双击 `start.bat` 或打开 `game.html` 即可开始，**无需安装任何环境**（推荐 Chrome/Edge 浏览器，按 F11 全屏）。

| 结束回合 | 点击「结束回合」或按 Enter/Space |

## 游戏规则

### 目标
摧毁所有敌方大本营，或消灭所有敌方单位。

### 流程
1. 所有玩家轮流操作——**所有玩家都行动完 = 1 回合**
2. 单位每回合可：**先移动 → 后攻击**（或跳过/驻扎）
3. **新造单位当回合不能行动**，休息到下回合才可操作
4. 操作完成后玩家颜色边框变细，表示该单位本回合已行动

### 玩家颜色
| 玩家 | 颜色 |
|:---:|:----:|
| P1 | 🔴 红 |
| P2 | 🔵 蓝 |
| P3 | 🟢 绿 |
| P4 | 🟡 黄 |

### 战斗公式
```
伤害 = max(0, 攻击方攻击力 − 防守方护甲) × 攻击次数
```
- 轰炸机仅对单目标造成伤害，不再乘以爆炸半径
- 装甲车攻击 3 次
- 轰炸机每 2 回合攻击一次（装弹 1 回合）

### 金钱与经济
- 起始资金：**10 金币**
- 所有数值运算保留 **2 位小数**，杜绝浮点误差
- 大本营每回合产出金币（T1: +3, T2: +5, T3: +8）
- 据点被占领后每回合产出金币（+3）

### 资源采集器（T2 解锁）
- 建造费用：🪙8，建造时间：**2 回合**
- **产出递减**（按建造时间排序）：

| 第几个 | 每回合产出 |
|:-----:|:---------:|
| 1 | 🪙 3.00 |
| 2 | 🪙 2.40 |
| 3 | 🪙 1.92 |
| 4 | 🪙 1.54 |

- 建造虚影上会显示**预计每回合产出**

### 大本营升级
| 等级 | 费用 | 时间 | 效果 |
|:---:|:----:|:----:|:-----|
| T1→T2 | 🪙10 | ⏳3 回合 | HP 50, 护甲 0.5, +5金币, 双联炮台 |
| T2→T3 | 🪙30 | ⏳**6** 回合 | HP 120, 护甲 1, +8金币, 终极炮台 |

### 建筑自回血
所有建筑连续 2 回合未受攻击后，从第 3 回合起每回合自动恢复 **2 HP**，受击即中断。

### 据点系统
- 地图上分布中立据点，初始 20 HP、0 护甲
- **可反复易手**：谁打爆最后一滴血 → 据点归谁
- 占领瞬间重置为 **30% HP**（至少 1 HP）
- 占领后自动获得 T2 级防御炮台（2×2 伤害，射程 5）
- 占领后每回合 +3 金币

## 地图

| 人数 | 地图尺寸 | 布局 |
|:---:|:--------:|:----|
| 2人 | 50×50 | 大本营在 y 轴中线左右，垂直平分线竖排3个据点（间距10格，上左偏3下右偏3） |
| 3人 | 60×60 | 大本营三角分布，据点在中线和中心 |
| 4人 | 80×80 | 大本营四角分布，据点在中线和中心 |

- **地形**：草地、森林（移速×2）、山地（移速×3）、水域（不可通行）
- **空中单位**（战斗机/轰炸机）：无视地形和单位阻挡，每格消耗1移速

## 胜利结算

当只剩 1 名玩家存活时，弹出结算画面并显示 **4 张折线图**：

| 图表 | 内容 |
|:----|:------|
| 📈 军队价值 | 各玩家单位总价格随回合变化 |
| 📈 金币总数 | 各玩家持有金币变化 |
| 📈 累计击杀 | 各玩家摧毁敌方总价值 |
| 📈 回合收入 | 各玩家每回合金币收入 |

各玩家用对应颜色折线表示（🔴🔵🟢🟡）。


### 技术架构
- **渲染**：HTML5 Canvas，60fps requestAnimationFrame
- **摄像机**：平滑 lerp 缩放/平移，滚轮以光标为中心缩放
- **类结构**：`Game` → `Grid` / `Camera` / `Unit` / `Building` / `Player`
- **寻路**：BFS 移动范围（支持地形消耗和空中无视地形）
- **攻击范围**：曼哈顿距离
- **存档**：无需存档，热座模式同一台电脑轮流操作
